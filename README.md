# DragonPazzle

Android application project for DragonPazzle.

## Project Details

- **Min SDK**: 24
- **Target SDK**: 35
- **Compile SDK**: 35
- **Language**: Kotlin
- **Build System**: Gradle (Kotlin DSL)

## Dependencies

- AndroidX Core KTX
- AndroidX AppCompat
- Material Design
- ConstraintLayout
- AppsFlyer SDK
- OkHttp 3

## Build Variants

- **Debug**: Full symbols and debugging support
- **Release**: ProGuard minification and resource shrinking enabled

## Setup

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle files
4. Build and run the application
